## 👨‍💻 Hakkımda

Fırat Üniversitesi Yazılım Mühendisliği mezunuyum.

Yazılım geliştirme çalışmalarımda özellikle **C# / .NET backend geliştirme** ve  
**web test otomasyonu** alanlarına odaklanıyorum.

.NET projelerimde ASP.NET Core MVC, Web API, Entity Framework Core ve SQL Server kullanarak;
katmanlı mimari, Repository Pattern, Dependency Injection, DTO yapıları, AutoMapper,
kimlik doğrulama ve API entegrasyonları üzerine çalışmalar gerçekleştiriyorum.

Test otomasyon tarafında ise Playwright, Selenium ve Cucumber kullanarak
okunabilir, sürdürülebilir ve CI/CD süreçlerine entegre edilebilir test frameworkleri geliştiriyorum.

Yeni teknolojiler öğrenmeye, mevcut bilgilerimi gerçek projeler üzerinde geliştirmeye
ve temiz kod prensiplerine uygun çözümler üretmeye önem veriyorum.
